# relativist1.github.io

Personal website of Saurabh, astrophysicist.

A static site served by GitHub Pages: plain HTML, CSS and JavaScript, no build step.

- `index.html`: homepage. The background is a live ray-traced Kerr black hole (`bh.js`); `site.js` moves the camera as you scroll.
- `research.html`, `simulations.html`, `simulate-accretion.html`, `writing.html`: inner pages.
- `essay-template.html`: copy this to start a new essay, then add a line for it to the list in `writing.html`.
- `img/`: images. `img/poster.jpg` is the still image shown when a browser cannot run WebGL.

The previous Jekyll site is kept on the `old-site` branch.
